# QOSS lab website — antonsolanaslab.com

Built with [Astro](https://astro.build), hosted on GitHub Pages, edited with [Pages CMS](https://app.pagescms.org).

## Everyday edits (no code)
1. Go to https://app.pagescms.org and sign in with GitHub.
2. Open this repository.
3. Pick what to edit in the left menu: **News**, **Publications**, **People**, **Seminars**, **Projects**, **Page texts**.
4. Click **Save**. The site rebuilds automatically and is live in ~1–2 minutes.

## Where things live
- `src/data/*.json` — news, publications, team, alumni, visitors, seminars, open hardware
- `src/content/projects/*.md` — one file per project (POEM, ECO-Q, COMPHORT)
- `src/content/pages/*.md` — page texts (home, research, people bio, teaching, outreach, join us, contact; `-es` = Spanish)
- `public/img/` — images
- `public/js/hbt.js`, `public/js/hom.js` — the pixel-art animations
